# ODYSSEUS: I Have Read This Book — A Playable Epic

**Play now / 立即遊玩:** https://gamegen-diy.github.io/odysseus-cinema/

An interactive-cinema epic: you wake up inside Odysseus the night the Trojan Horse is finished — and you have read the entire book. Cinematic AI visuals, English voice-over, subtitles in **English / 繁體中文** (switch in the ☰ menu), choice cards with tone tags, and a persuasion-meter boss fight against the Cyclops.

互動式電影:木馬完工那一夜,你在奧德修斯的身體裡醒來——而你讀過整本史詩。電影級 AI 畫面+英文配音,字幕可切英文/繁體中文(右上 ☰ 選單),選擇卡帶語氣標籤,還有對獨眼巨人的「說服計量條」BOSS 戰。

## How to play / 怎麼玩
- Tap to advance the story; pick a card to choose. / 點畫面推進劇情,點卡片做選擇。
- Boss scene: read the 👁 intel, cross the gold line to survive. / BOSS 戰:讀 👁 情報,把說服條推過金線才能活。
- ☰ menu: voice / music / autoplay / **language** / restart. / 選單:語音/音樂/自動播放/**語言**/重來。
- Progress autosaves every scene. Best with sound on. / 進度每場自動存檔。建議開聲音。

3. Which choice did you regret? / 哪個選擇讓你後悔?
4. EN vs 中文 subtitle preference on mobile. / 手機上習慣看英文還是中文字幕?
